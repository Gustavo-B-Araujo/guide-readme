# Guide - Readme

Neste projeto, descrevo brevemente o que é e qual é a finalidade de um arquivo Readme.md.


## O que é?

Este é o cartão de visita de um projeto. É o primeiro arquivo a ser visto em um repositório.


## E serve para?

Explicar o que é, o que faz e como usar o seu projeto.


## Qual é a estrutura do documento?

Não tem um padrão cravado na pedra (mas é bom seguir uma lógica)!


## Estrutura mais básica possível

- Título
- Descrição
- Índice
- Features|Características
- Requisitos
- Instalação
- Como usar
- Exemplos
- Licença
- Autor + Contato


## Sintaxe básica

### Título

Os títutlos são criados com "#" e vão do nível 1 ao 4. Exemplo:
- Título principal:   `#`
- Subtítulo:          `##`
- Seção:              `###`
- Subseção:           `####`

### Ênfase
- Texto em negrito:   `** **`
- Texto em itálico:   `* *`
- Texto riscado:      `~~ ~~`

### Listas
- Ordenada:           `1. `
- Não-ordenada:       `-`

### Linhas horizontais:
- Primeira opção: `---`
- Segunda opção: `***`

### Blocos de código
- Inline: `\exemplo install\`
- Bloco: `\\\exemplo instal\\\`
